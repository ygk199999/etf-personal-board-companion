QQQ·QLD 신규 입금 배분 (contribution_plan)
- 현재 보유 평가금액 + 이번 투입금을 합쳐 QQQ 계열 50%, QLD 50%에 가깝게 매수만 배분합니다.
- QQQM은 core_symbols의 QQQ 계열로 합산합니다. 기존 QQQM 보유를 매도하도록 안내하지 않습니다.
- 매수 대상은 core_buy_symbol(QQQ)과 leveraged_symbol(QLD)입니다.
- 새 돈이 부족하면 부족 비중 쪽에 전액 배분하고, 목표 달성 불가와 매수 후 예상 비중을 표시합니다.
- funding_source: usd_cash는 KB USD 예수금 조회값을 투입금으로 자동 반영합니다.
  예수금은 실제 주문 가능액과 다를 수 있고, 미체결·수수료·세금은 반영하지 않습니다.
- 수동 계획은 funding_source를 manual로 바꾸고 currency(KRW/USD), amount(추가 금액)를 입력합니다.
  usd_cash 모드에서는 수동 amount를 더하지 않습니다. 원화 예수금은 자동 환전해 사용하지 않습니다.
- core_target_percent는 QQQ 계열 목표이며 나머지는 QLD 목표입니다. 기본 50입니다.
- 다른 보유 종목은 두 그룹의 비중 계산에서 제외하며 화면에 이를 표시합니다.
- 월 정기 적립 유지, 황현희식 -15/-20/-25/-30/-35%는 추가 매수 알림 기준으로 유지합니다.
- dip_strategy.signal_only=true에서는 고정 대기자금·단계별 금액을 안내하지 않습니다.
  실제 투입금은 위 신규 입금 계획으로 배분하며, 알림이 주문하거나 현금을 차감하지 않습니다.
- 기존 starting_cash_krw 등은 과거 기록 호환용입니다. signal_only에서는 활성 매수 예산이 아닙니다.
- 아래 전체 계좌 표는 보유내역입니다. 이 모드에서는 기존 리밸런싱 매도 안내를 표시하지 않습니다.

ISA · IRP 수기 계좌
- 화면의 '수기 계좌 편집'에서 JSON을 입력하면 config.json의 manual_accounts에 저장됩니다.
- 같은 내용을 Wallpaper Engine의 설정 JSON에 manual_accounts로 넣어도 됩니다.
- 각 계좌 id는 isa 또는 irp이며 계좌별로 따로 계산합니다. 모든 금액은 원(KRW)입니다.
- cash: 현금(없으면 0, 미입력은 null). as_of: 앱에서 확인한 기준일 YYYY-MM-DD.
- holdings: 종목 배열. 종목마다 symbol(코드), name(이름), quantity(수량), value(총 평가금액), target_percent(목표 비중)를 입력합니다.
- quantity는 모르면 null. value는 해당 종목 전체 평가금액이며 1주 가격이 아닙니다.
- 종목 예시(본인 보유내역이 아닌 입력 형식):
  {"symbol":"069500","name":"ETF 이름","quantity":null,"value":0,"target_percent":null}
- cash_target_percent와 모든 종목 target_percent 합계가 100%여야 리밸런싱을 계산합니다.
- contribution: 아직 현금에 포함되지 않은 추가 투입금. drift_threshold_pp: 허용 오차(%p).
- 수기 평가금액은 자동 시세 갱신되지 않습니다. 기준일과 평가금액을 직접 갱신하세요.
- KB 자동 조회 잔고와 달러 자산에 합산하지 않습니다. 미입력 현금·잔고는 0원으로 가정하지 않습니다.

달러 자산 원화 환산
- 달러 총자산·종목별 평가금액·달러 예수금·시세에 원화 참고 환산액을 함께 표시합니다.
- USD/KRW Yahoo Finance 참고 환율의 기준 시각과 조회 시각을 표시합니다.
- 은행의 실제 환전 적용환율이 아니며 환전 수수료는 포함하지 않습니다.
- 환율 갱신 실패 시 이전 값임을 표시하고, 최초 환율이 없으면 환산 대기로 표시합니다.

시세 목록과 계좌 보유내역
- assets는 위쪽 시세 카드 목록입니다. 실제 계좌 보유내역과 일치할 필요가 없습니다.

- 시세 목록에 없는 보유 종목의 목표는 rebalance.position_targets에서 지정합니다.
  예: "position_targets": {"VTI": null}. null은 미설정이며 목표값을 임의로 정하지 않습니다.
- 실제 보유 종목의 목표를 설정하지 않으면 리밸런싱 계산을 보류합니다.
- 원화 예수금은 별도 표시하며 USD 비중·매수 금액에 자동 환산해 더하지 않습니다.
- 같은 연결계좌의 CMA/원화 요약에는 오늘 예수금, 출금 가능 현금, D+2 예수금,
  국내 계좌 기준 순자산평가를 표시합니다. 예수금·달러 자산과 중복 합산하지 않습니다.

종목 변경
- assets 배열의 각 객체가 한 종목입니다. 객체 순서가 카드와 표의 순서입니다.
- 추가: 객체를 하나 복사하고 symbol을 VTI 같은 Yahoo Finance 티커로 변경.
- 삭제: 해당 객체를 제거. 마지막 객체 뒤에 쉼표를 남기지 마세요.
- symbol: 대문자 티커. USD로 시세를 제공하는 종목만 지원합니다.
- name: 정식 이름. 화면 폭이 좁으면 축약되며 종목 설명에 보관됩니다.
- category: 카드 오른쪽에 보일 분류.
- color: #RRGGBB 형식의 차트·비중 표시 색.
- target_percent: 목표 비중 %. null이면 미설정이며 리밸런싱 계산을 하지 않습니다.
- quantity: 수동 보유 수량. KB 연결 후에는 실제 조회 수량이 화면에 우선 적용됩니다.
- 종목 수: 1~24개. 종목이 많으면 카드/표 내부를 스크롤합니다.

리밸런싱
- rebalance.cash_target_percent: 현금으로 남길 목표 비중. 기본 0%.
- 모든 종목의 target_percent + cash_target_percent 합계가 100%여야 합니다.
- rebalance.drift_threshold_pp: 허용 오차. 기본 5%p.
  종목/현금의 현재 비중과 목표 비중 차이 중 최댓값이 이 기준 이상이면
  전체 목표 비중에 맞춰 조정합니다. 0은 오차 없이 목표 비중에 맞추는 설정입니다.
  기준 미만이면 '유지'와 조정금액 0을 표시합니다.
- rebalance.cash_usd: 수동 달러 현금. KB 연결 후에는 달러 예수금이 우선 적용됩니다.
- rebalance.contribution_usd: 새로 추가할 예정 금액. 아직 입금되지 않은 돈만 입력하세요.
  이미 계좌 현금에 포함된 돈을 다시 넣으면 중복 계산됩니다.
  추가 투입금이 있으면 허용 오차와 관계없이 목표 비중으로 다시 계산합니다.
- 목표 자산 = (보유 종목 평가금액 + 달러 현금 + 추가 투입금) × 목표 비중.
- USD 이외의 주식은 계산에 포함하지 않으며 해당 항목이 있으면 계산을 보류합니다.
- 설정을 '적용'하는 것은 계산 조건 변경이며 실제 주문을 실행하지 않습니다.

시세와 지표
- refresh_seconds: 60~3600초. 기본 120초.
- indicators.rsi_period: Wilder RSI 기간. 2~100일, 기본 14일.
- indicators.history_range: MDD·차트 기간. 6mo, 1y, 2y, 5y, 10y, max.
- MDD와 고점 대비 하락률은 배당·분할을 조정한 완료 일봉 기준입니다.
- title: 화면 상단 제목.
- currency: 현재 USD만 지원합니다. 통화 변환 기능은 아직 없습니다.

오류 처리
- 실행 중 문법·값 오류: 화면에 오류 표시, 마지막 정상 설정 유지, 잘못된 파일은 보존.
- 최초 실행부터 잘못된 JSON: 오류 메시지 표시. 파일을 고치면 자동 복구.
- 목표 합계가 100%가 아님: 시세는 계속 표시하고 조정금액 계산만 보류.
- 중복 티커, 잘못된 색상, 음수·무한대·NaN, 지원하지 않는 기간은 차단.
- API 키는 config.json에 넣지 마세요. Setup KB API.cmd의 암호화 저장을 사용합니다.

하락장 분할 매수 (dip_strategy)
----------------------------
signal_only=true: 낙폭 알림만 사용합니다. 아래 금액/체결 안내는 signal_only=false인 기존 대기자금 모드용입니다.
enabled: 사용 여부. signal_symbol: 낙폭 신호 종목 (기본 QQQM).
lookback_sessions: 시작 기준 고점 산정 기간 (기본 252 완료 거래일 종가).
starting_cash_krw: 최초 대기자금. cash_adjustment_krw: 이후 추가/인출한 순금액 누계.
strategy_name: 화면에 표시할 전략 이름. levels_percent: 오름차순 낙폭.
allocation_mode: equal_parts는 회차 준비자금을 단계 수로 균등 분할합니다.
remaining_percent는 단계마다 남은 현금의 spend_remaining_percent만큼 계획합니다.
equal_parts에서는 spend_remaining_percent를 사용하지 않습니다.
현재 적용 예: 황현희식 지수 분할 매수, [15,20,25,30,35]에서 준비자금 5등분.
1,000만원이면 각 200만원입니다. 체결 후에도 남은 단계 금액은 200만원으로 유지합니다.
잔액보다 큰 금액은 안내하지 않습니다. 회차 중 추가 입금은 자동으로 분할 금액을 늘리지 않습니다.
원 단위 나눗셈의 잔액은 마지막 단계에 배정합니다.
보도마다 시작 낙폭이 달라 이번 설정은 15% 시작 보도를 기준으로 정했습니다.
참고: https://view.asiae.co.kr/article/2026072309382270703
252일 고점, 완료 일봉, 월 적립 유지, 고점 회복 후 재시작은 이 대시보드의 운영 규칙입니다.
월 적립금은 기존 설정 그대로이며 대기자금 자동 충전은 하지 않습니다.
대기자금은 계획용 기록입니다. KB 현금과 별도로 자산 총액에 더하지 않습니다.
장중 시세가 아닌 완료 일봉 종가로 판단합니다. 시작 시 최근 252거래일 최고 종가를 쓰고,
첫 단계 도달 후에는 고점을 고정합니다. 고점 회복 시 다음 회차로 넘어가지만 잔액은 유지합니다.
조건 충족은 화면에 표시하며 자동 주문하거나 현금을 차감하지 않습니다.
