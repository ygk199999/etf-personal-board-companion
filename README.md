# ETF Personal Board — Local Companion

Wallpaper Engine에 시세·RSI·MDD·보유 자산 데이터를 제공하는 Windows 로컬 Python 서버입니다.

## 설치

1. 이 저장소를 다운로드하고 Windows에 Python 3.13을 설치합니다.
2. `Start ETF Board.cmd`를 한 번 실행합니다. 별도 Python 패키지는 필요하지 않습니다.
   로그인 시 로컬 서버 자동 실행이 등록되고, 서버가 종료되면 15초 간격 확인 후 재시작합니다.
   창은 숨겨 실행합니다. 자동 실행을 해제하려면 Windows 시작프로그램 폴더의
   `ETF Personal Wallpaper` 바로가기를 삭제하고 로컬 상태 폴더의 `supervisor.pid` 프로세스를 종료합니다.
3. `http://127.0.0.1:8766/`에서 미리보기를 확인합니다.
4. Steam 창작마당에서 월페이퍼를 구독합니다. 로컬 서버는 실행 중이어야 합니다.

## 설정

최초 실행 시 `config.example.json`을 복사해 `config.json`을 만듭니다.
`Edit Config.cmd`에서 종목·보유 수량·목표 비중·현금·허용 오차를 편집합니다.
월페이퍼의 `JSON 편집` / `수기 JSON 편집` 버튼도 실제 적용 중인 파일을 외부 메모장으로 엽니다.
저장하면 자동 반영됩니다. Downloads에 내보낸 JSON은 별도 복사본입니다.
설정은 자동 반영됩니다. 필드 설명은 `CONFIG_GUIDE.txt`를 참고하세요.
개인 설정 파일 `config.json`은 Git에서 제외되며 예제에는 실제 보유내역이 없습니다.

Wallpaper Engine 속성의 `포트폴리오 설정 JSON`, `KB 계좌 자동 연결`, `KB 로컬 프로필 이름`도
네이티브 JSON 프리셋으로 저장할 수 있습니다. 속성 변경은 로컬 서버에 반영됩니다.
인증키는 프리셋에 포함하지 않습니다. 기본 프로필 이름은 `default`이며,
다른 프로필을 등록하려면 `py -3.13 kb.py --profile 프로필이름`을 실행합니다.

## KB 연동

KB Open API 사용 신청 후 `Setup KB API.cmd`에서 인증키를 입력합니다.
키는 Windows DPAPI로 암호화해 사용자 로컬 데이터 폴더에 저장합니다.
키와 실제 계좌 정보를 저장소나 이슈에 올리지 마세요.
주문 기능 없이 잔고 조회만 수행합니다. 인증·해외주식 잔고·달러 예수금 실조회를 확인했습니다.
조회 요청에는 PC의 KB 접속 경로 IP와 기기 MAC 정보를 포함합니다.
계좌별 API 권한·통화·연속 조회 여부에 따라 추가 확인이 필요할 수 있습니다.

## 데이터 기준

ISA·IRP는 화면의 `수기 계좌 편집` 또는 `manual_accounts` JSON으로 입력합니다.
보유 종목의 원화 총 평가금액, 현금, 수량(선택), 기준일과 목표 비중을 저장합니다.
각 계좌의 종목·현금 목표 합계가 100%이면 계좌별로 리밸런싱을 계산합니다.
수기 평가금액은 자동 갱신되지 않습니다. 입력하지 않은 잔고는 0으로 간주하지 않습니다.
USD 자산·보유 종목·예수금에는 USD/KRW 참고 환율로 원화 환산액을 함께 표시합니다.
환율 기준 시각과 조회 시각을 표시하며 실제 은행 환전율·수수료는 반영하지 않습니다.

USD 종목 1~24개, Yahoo Finance 비공식 시세이며 거래소 실시간을 보장하지 않습니다.
RSI·MDD는 배당·분할 조정 완료 일봉 기준입니다.
시세 카드 목록과 실제 계좌 보유내역은 별개입니다. 시세 목록 밖의 USD 보유 종목도 자산 표에 표시합니다.
원화 예수금은 별도로 보여주며 USD 자산 비중에 자동 환산해 더하지 않습니다.
시세 목록 밖 보유 종목의 목표는 `rebalance.position_targets` 또는 자산 설정창에서 편집합니다.
같은 연결계좌의 CMA/원화 요약에는 오늘 예수금, 출금 가능 현금, D+2 예수금,
국내 기준 순자산평가를 표시합니다. 이 참고 금액을 다른 자산과 중복 합산하지 않습니다.
수수료·세금·환전·미체결 주문은 미반영입니다.
서버는 127.0.0.1에만 바인딩합니다. Steam 월페이퍼는 HTML/CSS/JS를 직접 렌더링하고
로컬 서버에서 데이터를 읽습니다. 별도 iframe이나 주소 전환을 사용하지 않습니다.
일반 브라우저 미리보기는 파일을 직접 열지 말고 http://127.0.0.1:8766/ 로 접속하세요.
